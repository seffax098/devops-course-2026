Что удобно делать с Git в VS Code:
Смотреть изменения. Во вкладке Source Control видно все изменённые файлы. Если кликнуть по файлу, изменения открываются бок о бок (было / стало), и так проще проверить код перед коммитом, чем читать git diff в терминале.
Выбирать, что попадёт в коммит. Файлы можно добавить в индекс кнопкой «+», а отдельные строки или фрагменты — через «Stage Selected Ranges». В терминале для этого нужен git add -p, и там легче ошибиться.
Разрешать конфликты слияния. VS Code подсвечивает конфликтующие блоки и предлагает кнопки «Accept Current», «Accept Incoming» и «Accept Both». 

Что удобнее делать в терминале:
Смотреть историю и выполнять сложные операции. Например, git log --oneline --graph --all сразу показывает все ветки.
