1. Почему ветки в Git «дешёвые», а в SVN «дорогие»?
В Git ветка — это просто указатель на коммит. Она создаётся мгновенно и без сервера, а сливать ветки легко. В SVN ветка — это копия каталога на сервере: для неё нужна сеть, часто отдельный checkout, и слияние сложнее.

2. Можно ли в SVN сделать коммит без интернета?
Нет. SVN централизованный: история хранится на сервере, и коммит отправляется прямо туда. Без сети можно только править файлы и смотреть svn diff и svn status.

3. Когда SVN может быть лучше Git?

Много больших бинарных файлов (игры, дизайн, видео).
Нужна блокировка файлов, которые нельзя слить.
Нужно скачать только часть большого репозитория.
Нужны права доступа на отдельные папки.
Старые проекты, где всё давно построено на SVN.
